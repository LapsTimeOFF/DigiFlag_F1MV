# 🚩 Requirements

- [An Active Subscription to F1TV](https://f1tv.formula1.com/)
- [MultiViewer App](https://multiviewer.app/)

# 🏎️ Install

1. Click on the Release Badge below to download the latest release of DigiFlag for your corresponding Operating System
   (Windows/Mac/Linux).

   [![GitHub release (latest SemVer)](https://img.shields.io/github/v/release/LapsTimeOFF/DigiFlag_F1MV?color=%235FAD56&include_prereleases&style=for-the-badge)](https://github.com/LapsTimeOFF/DigiFlag_F1MV/releases/latest)

2. (Windows/Linux) Extract the downloaded archive.

   2a. (Mac) Open DMG File & Install Like Any Other App.

# 🏁 Usage

1. Launch the MultiViewer application.
2. Choose a Practice, Qualifying, or Race session.
3. Open the Live Timing or Replay Live Timing window.
4. Start DigiFlag for MultiViewer.
5. DigiFlag will automatically try to connect to MultiViewer.
6. Pick your preferred theme.
7. Adjust any additional preferences.
8. Click the **Start DigiFlag** button.

Tip: You can zoom in or out using the icons in the bottom-right corner, or resize the DigiFlag window by dragging it to
fit your preference.

# 🧰 Troubleshooting

If you receive an error stating that you have failed to connect to MultiViewer.

Follow the steps below

1. Click on the **Open MultiViewer** button to launch MultiViewer.  
   ![Open MultiViewer](https://github.com/user-attachments/assets/2c49018d-163d-4c6c-b337-59ec5b2633ff)

2. In MultiViewer, navigate to the **Settings** menu, scroll down to the `Experimental Settings` section, expand the
   dropdown menu, and verify that the option `Allow all websites to access the API` is enabled to ensure smooth
   operation and avoid potential issues.

   ![Experimental Settings](https://github.com/user-attachments/assets/ff838bac-cdb5-41aa-832f-6e44af4a012b)

3. Wait while DigiFlag automatically attempts to connect to MultiViewer every few seconds.

   ![Attempting Connection](https://github.com/user-attachments/assets/bcdaac6a-27b7-4345-9b43-047e22a6280f)

4. Once successfully connected to **MultiViewer**, you can then choose your DigiFlag theme along with other available
   options.

   ![DigiFlag Options](https://github.com/user-attachments/assets/ec7ca47a-350c-47f6-bd0e-9cc88fc04a8d)
